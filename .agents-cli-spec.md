# Agent Specification: SwagCraft

## Problem Statement
Users want an agentic swag studio where they can enter any company name (and optional swag item selection or "Surprise Me"), have the agent search the web for the company's latest achievements, brand identity, and news, and generate a customized product showcase of typical company swag (e.g. steel water bottle, stickers, hoodie, socks, desk mat, tote bag) with a realistic product mockup photo rendered using `gemini-3.1-flash-lite-image` (Nano Banana 2 Lite). The agent displays the result in a clean card format with the product image rendered directly underneath.

## User Persona & Scenarios
- **Marketer / HR / Founder**: Inputs "Google DeepMind" and selects "hoodie" (or "surprise me").
- **Agent Workflow**:
  1. Searches Google for recent updates, milestones, and brand aesthetic of the company.
  2. Synthesizes a celebratory swag concept, milestone tagline, and product description.
  3. Uses `generate_swag_mockup` tool (`gemini-3.1-flash-lite-image`) to generate a photo mockup of the swag item, uploads it to the public Cloud Storage bucket `bwg3-qwiklabs-gcp-04-cf18a37c5cc8`, and returns the public URL.
  4. Renders an A2UI product card containing the item name, company milestone tagline, product description, and the rendered product image.

## Tools & Integrations
- `google_search`: ADK GoogleSearchTool to ground brand news, mission, and achievements.
- `generate_swag_mockup`: Function tool using `gemini-3.1-flash-lite-image` on Vertex AI (location: `global`) to generate product images and upload them to GCS.
- `pick_surprise_item`: Function tool to randomly select an exciting swag item when the user chooses "surprise me" or doesn't specify an item.
- `a2ui_callback`: Formats A2UI v0.8 card JSON for rendering in ADK Web dev UI and the custom web frontend.

## Deployment Target
- Local prototyping first (`agents-cli playground` and local test runs). No automatic remote redeployments per user instructions.
